6. Try three experiments


What changes with restitution?
Set restitution to 1.00 and watch near-elastic wall bounces; then set 0.00 to make velocity along the impact normal vanish at contact. Drag remains a separate energy loss.


Why are some lanes idle?
Set particle count to 65, group size to 64. You need 2 groups = 128 dispatched lanes, but only 65 are active. The remaining 63 must exit at the bounds check.


What does the timestep do?
Compare 4 ms and 40 ms at the same gravity. The kernel uses an explicit fixed-step integrator. Larger steps can overshoot walls more and may be less accurate.


What does workgroup size do?
Change 32 ↔ 256. Watch group count and idle lanes change while the simulation math remains the same. Larger groups are not automatically faster on actual GPUs.


HLSL ↔ simulation mapping


cbuffer Params: Values entered on the left would be uploaded from CPU code into a constant buffer in a real D3D12 application.


Source / Destination: Each invocation reads one ball and writes its new state, avoiding cross-thread overwrites. The JavaScript implementation models this using separate arrays each step.


numthreads: Declares how many threads a group contains. The host dispatches ceil(count / GROUP_SIZE) workgroups.


SV_DispatchThreadID: Gives a global index. Use it to map a lane to one particle.


Limitations: No ball-to-ball collisions, no GPU parallel scheduling, no shader compilation and no hardware performance measurements in this browser view. It teaches dispatch structure and basic update equations only.
