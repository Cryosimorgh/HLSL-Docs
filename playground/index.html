      Dispatch notesPractical details behind workgroups and buffer layouts
      

        
Workgroup occupancy
65 particles at 64 threads per group dispatches 128 lanes. The last 63 lanes exit at the bounds guard.

        
Time integration
A larger timestep can overshoot collision boundaries and reduce precision. The particle simulation uses a fixed-step integrator.

        
Memory layout
Each invocation reads one particle and writes a distinct destination. A constant buffer supplies the common simulation parameters.

        
Execution distinction
The main workbench compiles HLSL and executes WGSL on WebGPU. The particle sandbox is a separate JavaScript teaching model.
